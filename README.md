# Galeria de Fotos com HTML Semântico

Exercício prático de HTML5 semântico: uma galeria de imagens e uma página de conteúdo editorial, estruturadas com tags semânticas em vez de `div`s genéricas.

## Tecnologias
- HTML5 (tags semânticas: `header`, `main`, `section`, `figure`, `figcaption`, `footer`)
- CSS3

## Como rodar
1. Clone ou baixe o repositório
2. Abra o arquivo `home.html` no navegador para ver a galeria de fotos
3. Abra o arquivo `teste.html` no navegador para ver a página de conteúdo editorial

## O que eu fiz
Estruturei as duas páginas usando tags semânticas do HTML5 (`header`, `main`, `section`, `figure`/`figcaption`, `footer`), aplicando a marcação correta para cada tipo de conteúdo — imagens com legenda na galeria e blocos de texto na página editorial — e estilizei ambas com CSS.
